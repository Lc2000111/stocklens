Ask the database

Ask a question in plain English. The AI agent writes SQL queries against stocklens.db (the screener's latest snapshot of 516 stocks, plus earnings and I/B/E/S estimates), runs them read-only, and answers from the results. You can open "Queries it ran" to check its work.

How it works: the agent (gpt-6-luna via Portkey) has two tools, get_schema and run_sql. The database is opened read-only and only single SELECT queries are allowed, so it can look but never change anything. It answers from the latest screener snapshot; click Refresh prices on the screener for current numbers. AI can make mistakes, so check key figures. Not investment advice.

Data: Yahoo Finance (prices, earnings) · LSEG I/B/E/S via WRDS (analyst estimates)
